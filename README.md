# Curious Mind: Introduction to Artificial Intelligence

## 1. Project Overview

**Curious Mind** is an educational project designed to introduce beginners to Artificial Intelligence (AI), its applications, its limitations, and the importance of responsible AI use.

The project explores fundamental AI concepts, machine learning, generative AI, real-world applications, responsible AI principles, and practical skills for using and evaluating AI tools.

The repository includes a module outline, six chapter files, practice questions, study materials, presentation and video planning documents, a mini-lecture script, project documentation, and quality-assurance materials.

### Project Goals

The project aims to:

- Provide a clear and complete learning module structure.
- Introduce AI concepts in a logical sequence.
- Develop learning materials appropriate for beginners.
- Include examples, learning activities, and assessment questions.
- Encourage critical evaluation of AI-generated information.
- Promote responsible and ethical AI use.
- Maintain clear documentation and quality-assurance procedures.

## 2. Learning Objectives

By the end of the learning module, learners should be able to:

1. Explain the meaning of artificial intelligence and identify fundamental AI concepts.
2. Describe basic machine learning approaches and terminology.
3. Explain generative AI and large language models at an introductory level.
4. Identify applications of AI in everyday life and different industries.
5. Recognise ethical concerns, privacy risks, bias, and limitations associated with AI.
6. Create effective prompts and critically evaluate AI-generated responses.
7. Apply responsible AI practices while maintaining independent judgement.

## 3. Learning Module Structure

The module is organised into six chapters, preceded by a module outline.

| Section | Learning material | Main topics |
|---|---|---|
| Module outline | [00 — Module Outline](content/introduction-to-ai.md/00-module-outline.md) | Course structure, learning objectives, learning sequence, assessments, and supporting materials |
| Chapter 1 | [What Is Artificial Intelligence?](content/introduction-to-ai.md/01-what%20is%20ai.md) | Introduction to AI, foundational concepts, examples, benefits, limitations, and responsible use |
| Chapter 2 | [Machine Learning Basics](content/introduction-to-ai.md/02-machine-learning-basics.md) | Machine learning concepts, learning approaches, classification, regression, evaluation, and overfitting |
| Chapter 3 | [Generative AI and Large Language Models](content/introduction-to-ai.md/03-generative-ai-llms.md) | Generative AI, large language models, capabilities, and limitations |
| Chapter 4 | [AI Applications](content/introduction-to-ai.md/04%20-ai-applications.md) | AI applications in everyday life and different industries |
| Chapter 5 | [Responsible AI](content/introduction-to-ai.md/05-responsible-ai.md) | Fairness, privacy, transparency, accountability, safety, and responsible use |
| Chapter 6 | [Practical AI Skills](content/introduction-to-ai.md/06-practical-skills-ai.md) | Prompt writing, checking AI outputs, evaluating information, and responsible AI use |

### Recommended Learning Sequence

1. Read the module outline to understand the course structure.
2. Study Chapters 1–6 in order.
3. Complete the learning activities and review questions.
4. Use the study guide and practice questions to reinforce understanding.
5. Review the references and apply the responsible AI principles discussed throughout the module.

**Content status:** The existence of a chapter file does not automatically mean that the chapter is complete. Review the chapter content against its learning objectives and the assignment requirements before submission.
