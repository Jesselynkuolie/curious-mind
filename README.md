## 2. Project Overview

Curious Mind is an educational project that introduces students and beginners to Artificial Intelligence (AI).

The project explains the basic concepts of AI, its applications, benefits, limitations, and responsible use through different learning materials.

## 3. Intended Learners

This module is designed for:
- Students who are new to Artificial Intelligence.
- Beginners interested in understanding AI.
- Learners who want to explore practical applications of AI.

No advanced knowledge of Artificial Intelligence is required.

## 4. Project Objectives

- Understand the meaning and basic concepts of Artificial Intelligence.
- Explore how Machine Learning and Generative AI work.
- Identify real-life applications of AI.
- Understand the benefits, limitations, and ethical concerns of AI.
- Develop practical skills for using AI responsibly.

## 5. Learning Outcomes

After completing this module, learners should be able to:

- Explain what Artificial Intelligence is.
- Describe the basic concepts of Machine Learning and Generative AI.
- Recognize AI applications in everyday life.
- Identify responsible and ethical ways to use AI.
- Apply basic AI tools and skills appropriately.

## 6. Module Contents

The module contains six chapters:

| Chapter | Topic |
|---|---|
| 1 | Introduction to Artificial Intelligence |
| 2 | Machine Learning Basics |
| 3 | Generative AI and Large Language Models |
| 4 | AI Applications |
| 5 | Responsible AI |
| 6 | Practical AI Skills |

## 7. Learning Materials

The project includes:

- **Markdown Chapters:** Detailed explanations of the six topics.
- **Study Guide:** Summaries and important concepts for revision.
- **Test Bank:** Practice questions to check understanding.
- **PowerPoint Presentation:** Visual presentation of the main concepts.
- **Video Tutorials:** Supporting explanations and demonstrations.
- **Resource Mapping:** Shows how the learning materials connect to each chapter.

## 8. How to Use This Repository

Learners are encouraged to follow this order:

1. Start with the module outline in `content/introduction-to-ai.md/00-module-outline.md`.
2. Read Chapters 1–6 in sequence to understand the topics.
3. Use the Study Guide to review important concepts.
4. Complete the Test Bank to check your understanding.
5. Refer to the PowerPoint Presentation for visual summaries.
6. Watch the Video Tutorials for additional explanations and demonstrations.

Teachers and reviewers can also refer to `resource-mapping.md`, `revision-summary.md`, and the files in the `review/` folder.
