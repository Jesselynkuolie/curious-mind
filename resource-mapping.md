# Resource Mapping

## 1. Purpose

This document explains how the six chapters of the AI Overview module are connected to the learning resources developed by the team.

It helps ensure that the Study Guide, Test Bank, PowerPoint Presentation, and Video Tutorials cover the same learning objectives.

## 2. Chapter-to-Resource Mapping

| Chapter | Main Topic | Study Guide | Test Bank | PowerPoint | Video Tutorial |
|---|---|---|---|---|---|
| Chapter 1 | Introduction to Artificial Intelligence | AI definitions, types, and basic concepts | AI fundamentals questions | Introduction to AI | Introduction to AI |
| Chapter 2 | Machine Learning Basics | Data, training, models, and machine learning | Machine learning questions | How Machine Learning Works | Machine Learning Basics |
| Chapter 3 | Generative AI and Large Language Models | Generative AI, LLMs, and how they work | Generative AI questions | Understanding Generative AI | Generative AI Explained |
| Chapter 4 | AI Applications | Examples of AI in everyday life and different industries | AI application questions | AI in Everyday Life | AI Applications |
| Chapter 5 | Responsible AI | Benefits, limitations, ethics, and responsible use | Responsible AI questions | Responsible Use of AI | Using AI Responsibly |
| Chapter 6 | Practical AI Skills | Prompting, checking AI outputs, and practical skills | Practical AI questions | Using AI Effectively | Practical AI Skills |

## 3. Learning Resource Purposes

| Resource | Purpose |
|---|---|
| Markdown Chapters | Provide the main learning content and explanations. |
| Study Guide | Summarize important concepts and help students review. |
| Test Bank | Check students' understanding through practice questions. |
| PowerPoint Presentation | Present the main ideas in a visual and organized format. |
| Video Tutorials | Explain important concepts through visual demonstrations and narration. |

## 4. Consistency Checklist

- [ ] All six chapters are included in the learning resources.
- [ ] Study Guide topics match the Markdown chapters.
- [ ] Test Bank questions are related to the learning objectives.
- [ ] PowerPoint slides cover the main concepts.
- [ ] Video Tutorials support the corresponding chapters.
- [ ] Terminology and explanations are consistent across all resources.
- [ ] All resources have been checked before submission.

## 5. Final Note

The resource mapping helps the team maintain consistency across the AI Overview learning materials. Each resource supports the same learning objectives while presenting information in a different format.
