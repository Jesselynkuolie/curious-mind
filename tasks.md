
# Curious Mind — AI Overview
## Project Task List and Completion Tracker

## 1. Project Goal

Develop a complete, well-organized set of AI learning materials that demonstrates a clear instructional design approach, accurate content, learner engagement, accessibility, and responsible use of AI.

The project must meet these two essential requirements:

1. Provide a complete content structure for the learning materials.
2. Complete at least one full chapter that demonstrates the overall design approach.

**Priority:** Complete and verify these two requirements before treating supporting materials as finished.

## 3. Essential Assignment Requirements

### A. Complete Content Structure

- [ ] Define the course overview, target audience, and prerequisites.
- [ ] Write clear course-level learning objectives.
- [ ] List every module and chapter in a logical learning sequence.
- [ ] Describe the purpose and key topics of every chapter.
- [ ] Define chapter-level learning objectives.
- [ ] Identify appropriate learning activities and assessments.
- [ ] Explain how the modules build on prior knowledge.
- [ ] Check that all planned chapters are represented in the repository.
- [ ] Review `content/00-module-outline.md` for completeness and consistency.

**Acceptance criteria:** The outline communicates the entire learning-material structure, its learning objectives, sequence, and assessment approach without relying on the reader to guess what is missing.

### B. One Fully Completed Demonstration Chapter

Primary file: `content/01-what-is-ai.md`

- [ ] Include the chapter title and introduction.
- [ ] State measurable chapter learning objectives.
- [ ] Explain the main concepts accurately and in sufficient detail.
- [ ] Organize the content with clear headings and a logical progression.
- [ ] Include relevant examples and explanations.
- [ ] Include a practical activity, worked example, or guided exercise.
- [ ] Add appropriate diagrams or visual descriptions where useful.
- [ ] Include key terms and definitions.
- [ ] Add knowledge-check questions.
- [ ] Provide correct answers and explanations for the questions.
- [ ] End with a chapter summary.
- [ ] Cite credible sources for factual claims.
- [ ] Check readability, accessibility, and Markdown formatting.
- [ ] Confirm that the chapter can be understood by the intended learners independently.

**Acceptance criteria:** The chapter is a complete learning experience, not merely an outline, a short summary, or a list of topics. It demonstrates the instructional design approach that can be applied to the remaining chapters.
