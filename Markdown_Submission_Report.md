# Markdown Submission Report — Stage 3

**Project:** Curious Minds – Introduction to Artificial Intelligence  
**Deliverable:** Markdown  
**Version:** Stage 3  
**Team:** Curious Minds

## 1. Introduction

This report explains how the team responded to the professor's feedback on the previous Markdown submission (Markdown V.0). It describes the improvements made in Stage 3, the feedback that was addressed, and the remaining limitations.

## 2. Professor's Specific Feedback

The professor provided the following feedback regarding Markdown V.0:

- The submission did not fully follow the given instructions.
- The overall content coverage was good.
- There were no images or sufficient visual resources.
- The Markdown materials could not adequately support the production of the Study Guide, PowerPoint Presentation, and Video Tutorials.

## 3. Professor's General Feedback

Based on the professor's comments, the main expectations for improving the learning materials were:

- Provide sufficient learning resources to support other deliverables.
- Include relevant images, figures, and illustrations.
- Ensure that the Markdown materials can be used as a foundation for producing the Study Guide, PPT, and Video Tutorials.
- Improve the overall completeness and usefulness of the learning resources.

## 4. Improvements and Actions Taken in Stage 3

In Stage 3, the team organized the Markdown materials into six chapters covering the Introduction to Artificial Intelligence module.

The repository also includes supporting learning materials and documentation, including the Study Guide, Test Bank, resource mapping, and other project documentation.

The resource mapping helps connect the chapter content with the corresponding learning materials and supporting deliverables.

These materials provide an organized foundation for the development of the project's learning resources.

## 5. Feedback Not Fully Addressed

Although the Markdown materials were organized into chapters and supporting documents, some of the professor's feedback was not fully addressed.

In particular:

- Relevant images, figures, and illustrations were not added to the Markdown materials.
- The lack of visual resources remains a limitation when using the Markdown as a reference for producing the Study Guide, PPT, and Video Tutorials.
- The repository still needs additional visual resources to provide stronger support for the other deliverables.

## 6. Remaining Limitations

The main remaining limitation is the lack of visual learning resources in the Markdown repository.

Although the content provides a foundation for the learning materials, additional images, diagrams, figures, and illustrations would make it more useful for developing engaging and visually supported learning resources.

## 7. Conclusion

In Stage 3, the team organized the Markdown materials into six chapters and included supporting documentation to provide a clearer structure for the project.

However, the professor's feedback regarding the lack of images and visual resources was not fully addressed. Further improvements are needed to ensure that the Markdown materials can adequately support the production of the Study Guide, PowerPoint Presentation, and Video Tutorials.
