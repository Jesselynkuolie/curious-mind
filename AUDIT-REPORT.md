## 9. Audit Method

The audit should be completed using the following procedure:

1. Review the assignment brief and marking rubric.
2. Inspect the current repository structure.
3. Open and read the module outline.
4. Read the complete demonstration chapter.
5. Compare the chapter and module outline with the assignment requirements.
6. Review required supporting materials and assessments.
7. Test internal links and verify file paths.
8. Review references, citations, and asset attribution.
9. Record findings, priorities, corrective actions, and evidence.
10. Recheck any files changed to resolve findings.
11. Complete the final decision only when sufficient evidence is available.

Where a check has not been performed, record it as pending rather than passed.
