# Project Assets

This folder stores supporting assets used in the
Curious Mind: AI Overview project.

Examples include:
- Diagrams
- Illustrations
- Presentation images
- Video thumbnails
- Storyboards
- Other approved visual materials

## Asset Guidelines

1. Use files that directly support the learning content.
2. Use clear, readable visuals.
3. Record the source of externally obtained assets.
4. Follow applicable copyright and licensing requirements.
5. Do not include private or sensitive personal information.
6. Use descriptive file names.
