## 1. Using AI as a Support Tool

Artificial intelligence (AI) can help learners brainstorm ideas, organize information, explain difficult concepts, practice skills, and receive feedback. However, AI should support the learning process rather than replace independent thinking, personal effort, or responsibility.

For example, a student preparing for a machine-learning examination can ask an AI tool to generate practice questions. The student should then attempt the questions independently, check the explanations against course materials, and identify areas that need further study.

AI-generated content may contain incorrect information, incomplete explanations, outdated facts, or biased assumptions. Therefore, users should treat AI responses as starting points for investigation rather than automatically accepting them as facts.

Key principle: Use AI to improve your understanding, not to avoid developing your own understanding.

## 2. Writing a Clear Prompt

A prompt is the instruction or question given to an AI tool. A clear prompt helps the tool produce a response that better matches the user's needs. However, even a well-written prompt does not guarantee that the response will be correct.

An effective prompt can include five components:

1. Task: What should the AI do?
2. Context: What background information does it need?
3. Audience: Who is the response intended for?
4. Format: How should the answer be organized?
5. Constraints: What limits or requirements should it follow?
6. Not every prompt needs all five components. Their usefulness depends on the task.
### Example: Improving a prompt

Initial prompt:

"Help me study machine learning."

This prompt is vague because it does not specify the topics, difficulty level, audience, or desired output.

Improved prompt:

"Create five beginner-level practice questions about supervised and unsupervised learning for a high-school student who is new to machine learning. Present the questions in a numbered list, then provide an answer key with short explanations in simple English. Keep each explanation under three sentences."

### The improved prompt is more specific because it defines:
| Component | Example in the prompt |
|---|---|
| Task | Create five practice questions |
| Context | Supervised and unsupervised learning |
| Audience | A high-school student new to machine learning |
| Format | Numbered questions followed by an answer key |
| Constraints | Simple English and explanations under three sentences |

### Practical tips for prompt writing:

- Use specific instructions instead of broad requests.

- Provide relevant background information.

- State the expected output format.

- Set appropriate limits, such as length, language, or difficulty.

- Refine the prompt when the first response does not meet your needs.

- Avoid including passwords, private records, or confidential information.

## 3. Evaluating AI Answers

An AI response may sound confident and well organized while still containing errors. Before using its output, evaluate it using the following checklist.

| Criterion | Question to ask |
|---|---|
| Accuracy | Are the facts, definitions, calculations, and examples correct? |
| Relevance | Does the response directly answer the question? |
| Completeness | Does it cover the important points without leaving out necessary information? |
| Clarity | Is the explanation understandable and logically organized? |
| Bias | Does it present assumptions or viewpoints unfairly? |
| Currency | Is the information up to date enough for this task? |
| Sources | Are the sources identifiable, reliable, and relevant to the claims? |

The importance of each criterion depends on the task. For example, currency is especially important when researching current regulations, statistics, or technology developments. Accuracy and completeness are essential when learning a new concept or solving a mathematical problem.

### Worked example: Evaluating a machine-learning claim

Suppose an AI tool gives the following statement:

"All machine-learning systems learn without labels."

**Step 1: Identify the problem**

The statement uses the word "all," making an overly broad claim about machine learning.

**Step 2: Check the concept**

Machine learning includes different approaches. Supervised learning typically uses labeled examples, while unsupervised learning typically identifies patterns in data without provided labels.

**Step 3: Verify the explanation**

Compare the statement with reliable course materials or an authoritative machine-learning textbook or educational resource.

**Step 4: Correct the claim**

A more accurate version is:

"Machine-learning systems use different learning approaches. Supervised learning typically uses labeled training examples, whereas unsupervised learning typically works with data without provided labels to identify patterns."

**Step 5: Learn from the mistake**

The example demonstrates why users should examine absolute statements such as "all," "always," and "never." These words are not necessarily wrong, but they often require careful verification.
## 4. Verifying Sources

When checking an AI answer:

1. Find the original source.
2. Prefer relevant official or academic sources.
3. Check publication dates.
4. Confirm that the source supports the exact claim.
5. Compare reliable sources for important facts.

## 5. Example of Critical Evaluation

Suppose an AI answer says:

"All machine-learning systems learn without labels."

This statement is too broad.

Supervised learning commonly uses labeled examples, while
unsupervised learning typically looks for patterns without
provided labels.

The user should verify the distinction and correct the
statement instead of copying it automatically.

## 6. Academic Responsibility

Before using AI for schoolwork:

- Read the assignment instructions.
- Follow the rules about AI assistance.
- Verify facts and sources.
- Write based on your own understanding.
- Disclose assistance when required.
- Avoid sharing confidential information with unapproved tools.
